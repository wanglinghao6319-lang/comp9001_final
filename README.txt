TripWise

How to run:
python3 main.py

To run the UI version:
python3 ui.py

After running the program, please choose 7. Load data first.
After finishing your changes, please choose 6. Save data.

Files:
main.py
ui.py
data.txt

Main features:
- Create more than one travel plan
- Choose destination by continent and country
- Add expenses
- View all expenses
- View expenses by category
- Delete an expense
- Save and load data using a txt file

Menu guide:

1. Create new travel plan
Use this to make a new trip plan. First choose a continent, then choose a
country. After that, enter the number of travel days and the total budget in
AUD. The program will calculate the daily budget.

2. View travel plan
Use this to see all travel plans that are currently in the program. It shows
the destination, number of days, total budget, and daily budget for each plan.

3. Add expense
Use this to add a spending record to one travel plan. If there is more than one
plan, choose the plan first. Then enter the travel day, category, description,
and amount. The program also shows the remaining budget after adding the
expense.

4. View all expenses
Use this to see every expense in one selected travel plan. It shows the day,
category, description, and amount. It also shows the budget summary.

5. View expenses by category
Use this to see category totals for one selected travel plan. For example, it
shows how much was spent on Food, Accommodation, Transport, Shopping,
Activities, and Other.

6. Save data
Use this to save the current travel plans and expenses into data.txt. If
data.txt already has old data, saving will replace it with the current data in
the program.

7. Load data
Use this to read saved travel plans and expenses from data.txt. It is best to
load data before adding new information if you want to keep the old saved data.

8. Delete expense
Use this to delete a wrong expense from a selected travel plan. The program
shows the expenses first, then you enter the number of the expense to delete.

9. Exit
Use this to close the program.
